Introdução

Bem-vindo ao entendimento da linguagem HTML!

HTML (Hypertext Markup Language) é a linguagem de marcação padrão para criar páginas da web. Ele é usado para estruturar o conteúdo da web e definir a aparência e o comportamento dos elementos na página.

Estrutura

Um documento HTML é composto por elementos, que são representados por tags. Cada elemento pode ter atributos que fornecem informações adicionais sobre o elemento. A estrutura básica de um documento HTML inclui as tags <html>, <head> e <body>.

Elementos

Os elementos HTML são representados por tags, que são delimitadas por sinais de menor (<) e maior (>). Alguns exemplos de elementos HTML incluem:

  • <h1> a <h6>: Cabeçalhos de diferentes níveis
  • <p>: Parágrafo
  • <a>: Link
  • <img>: Imagem
  • <ul> e <ol>: Listas não ordenadas e ordenadas

Atributos

Os atributos fornecem informações adicionais sobre os elementos HTML. Eles são especificados dentro da tag de abertura do elemento. Alguns exemplos de atributos incluem:

  • id: Identificador único para o elemento
  • class: Classe do elemento, usada para estilização
  • src: Fonte de uma imagem ou recurso externo
  • href: URL de destino de um link

Exemplo

Abaixo está um exemplo simples de um documento HTML:

        <!DOCTYPE html>
        <html lang="en">
        <head>
            <meta charset="UTF-8">
            <meta name="viewport" content="width=device-width, initial-scale=1.0">
            <title>Exemplo de HTML</title>
        </head>
        <body>
            <h1>Olá, Mundo!</h1>
            <p>Este é um exemplo de documento HTML e meu primeiro documento.</p>
        </body>
        </html>

Este exemplo cria uma página da web simples com um cabeçalho e um parágrafo.
